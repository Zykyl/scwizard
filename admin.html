🧨 리더보드 초기화

GitHub에서 버튼 한 번으로 초기화할 수 있습니다. (저장소 관리자만 실행 가능)
1. 아래 버튼으로 GitHub Actions 페이지를 엽니다.
2. Run workflow 를 누르고 확인 칸에 초기화 를 입력한 뒤 실행합니다.
3. 1~2분 뒤 공유 기록이 모두 지워지고, 각 플레이어 브라우저의 예전 기록도 다음 접속 시 자동으로 정리됩니다.

ℹ️ Firebase 기록을 지우려면 처음 한 번 Firebase 서비스 계정 키를 GitHub에 FIREBASE_SERVICE_ACCOUNT 이름으로 등록해야 합니다. (Firebase 콘솔 > 프로젝트 설정 > 서비스 계정 > 새 비공개 키 생성 → 저장소 Settings > Secrets and variables > Actions)
